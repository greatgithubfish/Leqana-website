01 · 基本说明

先说关键的三件事

主要数据保存在你连接的 Companion Server。使用云端 AI 服务时，完成相应功能所需的内容会发送给该服务。断开配对只清理本机数据，永久删除角色需在「设置 › 数据管理」中执行。

Leqana 是由 Leqana 项目维护者（下称“我们”）维护的 AI 陪伴应用。当前版本采用 iPhone 客户端连接用户自行运行的 Mac Companion Server 的方式；我们没有在产品中设置统一托管的聊天数据库。服务器部署者可以是你，也可以是你选择并信任的管理者。

本政策描述当前实现的数据处理方式。若你使用其他人部署的服务器，服务器管理者能访问其管理的数据，其处理方式还应由该管理者说明。Leqana 不以儿童为目标用户。

02 · 我们的产品处理哪些数据

聊天与角色资料
你输入的文字、模型回复、角色名称、性格、背景、语言和时区等，用于持续对话和角色体验。可选的用户昵称或显示名称也会保存。
记忆与状态
从聊天提取或由你添加的记忆、关系与情绪状态、变化记录、日程和生活事件，用于维持对话的延续性、角色生活和主动联系。
照片与音频
你主动选择上传的图片、外貌参考照片和声音样本，以及生成的照片和语音，用于媒体展示与相应生成能力。上传参考素材前需要确认使用权。
设备与配对信息
设备名称、平台、设备标识、配对状态及最近使用时间，用于识别已配对设备和访问控制。启用推送时还包括 Apple 推送令牌。
服务配置与凭据
你填写的服务地址、模型标识、API Key、自定义请求 Header 和相关选项，用于连接所选服务。凭据由 Companion Server 加密保存，不在 App 中作为服务列表的明文返回。
运行记录
服务端会记录请求 ID、请求方法、路由模板、响应状态、耗时和故障类型，用于排查问题；应用的请求日志不记录完整聊天、请求正文、查询参数或凭据。

当前 App 未集成广告、跨应用追踪或第三方行为分析 SDK。我们不通过这些组件收集你的聊天，也不将聊天用于广告画像。你自己的部署环境和所选服务可能有独立日志与数据处理行为。

03 · 数据何时会发送到第三方

功能调用由 Companion Server 发起。接收方取决于你配置的服务，可能位于本机、你的网络或其他国家与地区。

  • 对话模型：接收本轮消息、为回复提供的历史片段、角色设定，以及相关记忆、情绪、关系和生活信息。
  • 状态分析与日程模型：在相应功能启用时，接收分析或生成所需的聊天片段、已知记忆或角色与生活设定。状态分析可选择规则模式或关闭；日程可使用模板。
  • 语音服务：接收需要朗读的文字、声音与语言参数。在服务支持且你明确开启发送样本时，还可能接收上传的声音样本。
  • 图片服务：接收生成提示词、外貌与场景描述；启用并配置参考照片生成方式时，接收相应参考图片。
  • 外部媒体服务：接收角色标识、标签、分类或媒体标识，以检索、获取图片。
  • Apple 推送服务：服务器配置 APNs 且设备开启通知后，会发送设备推送令牌、消息标识、角色名称和通知内容。文字消息可能包含最多 180 字符的预览；语音和图片通知可能显示对应提示。通知内容可能在锁屏上显示。

第三方服务的保存期限、训练使用、访问权限及跨境处理受该服务自己的政策与配置约束。我们不能替你选择的服务承诺不保存或不训练。请在使用前查看其政策，并按需要选择本地服务、调整功能、关闭推送预览或停止使用相应能力。

04 · 系统权限与选择

  • 本地网络：用于连接局域网中的 Mac Companion Server。
  • 通知：用于主动消息提醒；可以在 iOS 设置中关闭，也可以调整锁屏预览。
  • 照片：通过系统选择器仅获取你选中的照片；保存图片到系统相册时申请添加照片权限。
  • 文件选择：用于导入你明确选择的声音样本或其他支持的文件。

当前版本不请求通讯录、精准定位或麦克风录音权限。拒绝照片或通知权限不会要求你提供替代隐私信息，相应功能可能无法使用。你可以随时在系统设置中管理授权。

05 · 保存位置、期限与安全

Companion Server：角色、聊天、记忆、状态、服务配置与受管理的媒体文件保存在你连接的服务器中，默认使用 Mac 上的本地数据库与文件目录。在你删除前，相关记录会为持续体验而保留；备份的保留由服务器管理者决定。

iPhone：缓存角色资料、每个角色最近的聊天、未确认的待发送消息、图片和语音。服务器地址保存在应用设置中，设备访问令牌保存在 iOS Keychain。缓存用于离线查看、恢复未确认发送和减少重复下载，并有容量管理。

服务端使用用户与角色访问校验、受管理文件权限、路径与符号链接限制，并对 Provider 凭据加密保存。客户端禁用网络磁盘缓存和自动重定向。聊天数据库并非全库加密；这些措施不能等同于端到端加密，也不能替代服务器本身的访问保护。

当前版本允许可信局域网的 HTTP 连接。如果连接公网服务器，应由部署者提供 HTTPS 和访问控制。云端内容的保存时间由所选服务决定。

06 · 你如何管理与删除数据

  • 管理记忆：在角色的记忆页面查看、编辑、归档或删除相应记忆。
  • 删除媒体：在相册、外貌参考照片或声音样本页面删除项目；删除语音附件时文字回复会保留。
  • 永久删除角色：在「设置 › 数据管理」确认删除，清除该角色的聊天、记忆、关系与情绪、生活记录、参考照片、声音及受管理的媒体。其他角色和共享 Provider 设置保留。
  • 断开配对：清除本机配对令牌、角色和聊天缓存、未发送消息、图片与语音缓存；服务器上的记录保留，重新配对后仍可能读取。
  • 管理服务：可修改或删除 Provider 配置、移除凭据，或关闭不需要的语音、图片、主动联系和模型分析能力。

删除角色后，服务器管理的媒体会进入持久化清理流程，暂时失败的文件删除会在后续重试。Mac 文件夹中的原始照片、外部服务的原文件、服务器备份及其他设备的离线缓存不随本次操作自动清除。若需要完整清理这些副本，请联系相应服务器或第三方服务管理者。

你可以通过下方邮箱提出访问、更正、删除或其他隐私问题。自托管数据的操作通常由你或服务器管理者完成；我们无法直接访问或删除没有提供给我们的服务器数据。

07 · 本网站与支持邮件

这些网页不设置广告、统计脚本、追踪像素或 Cookie，不收集表单信息，也不连接你的 Companion Server。本网站由 GitHub Pages 托管。GitHub 会为安全目的记录并保存访问者的 IP 地址，无论访问者是否登录 GitHub。相关数据处理详情请参阅 GitHub 隐私声明。

你通过邮件联系我们时，我们会收到邮箱地址、邮件内容及你主动提供的附件，仅用于处理请求和相关沟通。邮件由所用邮件服务提供商处理。请只提供必要的信息，不要发送 API Key、配对码、设备 token、完整数据库或未脱敏的聊天。支持邮件按处理请求和必要后续沟通的需要保留；你可以请求删除，依法需保留的记录除外。
