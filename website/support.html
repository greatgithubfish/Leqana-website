Frequently asked questions

常见问题

Leqana V1 需要 iOS 17 或以上版本，并连接自己运行的 Mac Companion Server。对话模型需配置；语音、图片与推送按需启用。

iPhone 无法连接 Mac，怎么办？
  1. 确认 Mac 上的 Leqana Server 正在运行，且 Mac 未休眠。
  2. 让 iPhone 与 Mac 连接同一网络。在 App 输入 Mac 的局域网地址和端口，例如 192.168.1.10:8787。
  3. 检查 iOS「设置 › Leqana」中的本地网络权限，以及 Mac 防火墙是否允许访问。
  4. 先点「检查连接」，再输入未过期的配对码。配对码有效期为 15 分钟。

真机上的 127.0.0.1 指向 iPhone 本身；它仅适合在 Mac 上的 iOS 模拟器连接同机 Server。公网连接需要可访问的部署地址及安全配置。

配对码过期，或配对失效怎么办？

在 Mac 的 Server 管理工具中生成新的配对码，再在 App 中重新配对。设备被注销、令牌失效或服务器被重新初始化时，也需要重新配对。

断开配对会清除本机缓存和未发送消息，但不会删除原服务器上的角色数据。重新配对到同一服务器后，可再次读取服务器历史。

如何添加或切换对话模型？

打开「设置 › Providers」，添加对话 Provider，填写服务提供的 Base URL、API Key（需要时）和 Model ID，先测试连接或生成，再保存。在聊天顶部的模型菜单中选择自动或指定服务。

本地模型需先在 Mac 上启动兼容服务，再使用「发现 Mac 上的本地模型」。切换服务会保留由 Companion Core 管理的角色、聊天、记忆与关系；下一条回复的上下文会发送到新选择的模型。

语音无法生成或播放怎么办？

先在语音 Provider 中测试朗读，再到角色的「声音」设置中选择服务、填写 Voice ID 并试听。确保所选服务支持当前接口、声音与返回格式。

部分 Ogg / Opus 返回格式需要 Mac 安装 FFmpeg，由 Server 转换成可播放格式。语音失败不会丢失文字回复，可以在消息处重试。服务需要付费时，请同时检查余额与权限。

如何让角色发照片，或使用自己的媒体库？

生成照片需要配置图片 Provider，再在「她 › 外貌与照片」填写外貌与参考素材。在相册设置中控制每日上限与是否允许发送。

可直接从 iPhone 上传照片；也可将照片放到「相册 › 设置」显示的 Mac 角色专属目录中，然后扫描。请使用显示的路径，同名角色的目录也彼此独立。你编辑的标签可以帮助角色挑选照片。

上传参考照片或声音样本前，请确认你拥有相应使用权。

为什么没有收到主动联系或推送？

在角色「主动联系」设置里确认功能已启用，并检查勿扰时段、联系频率、最小间隔和角色是否正在睡觉。策略不满足条件时，角色不会立即联系。

系统推送还需要 Mac Server 配置 APNs、App 签名支持推送，以及 iPhone 的通知授权。未配置推送时，主动消息仍会保存在服务器，重新打开 App 可以查看。可以在系统设置中控制锁屏预览。

离线时可以聊天吗？发送失败会丢失吗？

离线时可以查看已缓存的近期聊天，生成新回复仍需连接 Companion Server 及相应模型。已经尝试发送但未收到确认的消息会保存在本机，重新打开 App 后可以点重试。

重试沿用同一消息 ID，Server 会去重；如果服务器历史已包含这条消息，App 会消除待重试项。写操作不会无限自动重试。断开配对会清除本机未发送消息，因此请先处理你希望保留的内容。

如何永久删除角色和相关数据？

进入「设置 › 数据管理」，选择删除当前角色并确认。会删除这个角色的聊天、记忆、状态、生活记录及服务器管理的照片和声音，并清理本机缓存。

其他角色和 Provider 设置保留。Mac 文件夹原照片、外部媒体服务原文件、备份及其他设备离线副本需要另行处理。遇到暂时性文件删除失败，Server 会保留清理任务并重试。详细范围见隐私政策的数据删除说明。

需要订阅吗？AI 服务费用怎么算？

这份 V1 项目目前没有应用内订阅或付款功能。你选择的云端对话、语音、图片或外部媒体服务可能独立收费；本地模型则取决于你使用的设备和服务。

本页没有承诺应用商店正式版本的价格或发行日期，实际下载与价格信息以正式发布渠道为准。
